🔮 Transformer（自回归）
输出按 token 顺序流式到来。引擎一旦看到 <tool>…</tool> 完整闭合，立即执行并把返回值交给后续续写 —— 后半段文本可以引用真实执行结果。
🌊 Diffusion（扩散）
所有 token 并行“去噪”，越是语义关键的 token 越早定稿。于是关键词 / 工具内容常先于标记浮现，可能引发 延迟 · 误触 · 顺序颠倒 · 嵌套错乱，难以在流式中可靠地执行工具。
